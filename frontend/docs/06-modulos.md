# MODULOS
El producto cuenta con 4 modulos:
 
**Modulo Publico**
    -Inicio
    -Buscar servicios
    -Buscar barberos
    -Reservar turno
    -Confirmar turno
    -Login
    -Registro


**Modulo Cliente**
    -Perfil
    -Mis reservas
    -Historial
    -Cancelar turno

**Modulo barbero**
-Mi perfil
-Dashoard
-Agenda
-Disponibilidad
-Mis servicios

**Modulo Administrador**
-Dashboard
-Gestion de empleados
-Gestion de clientes
-Gestion de servicios
-Gestion de reservas
-Configuracion
