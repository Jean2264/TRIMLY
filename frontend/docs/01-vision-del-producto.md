# DESCRIPCION DEL PRODUCTO
    El software a desarrollar es una aplicacion web diseñada para permitir a barberias gestionar turnos, servicios, clientes y empleados desde una plataforma moderna, intuitiva y adaptable a distintos dispositivos.

# PROBLEMA QUE RESUELVE
    El problema en comun que tienen muchas barberias:
    reciben turnos por WhatsApp;
    anotan en papel;
    pierden reservas;
    olvidan horarios;
    no tienen historial de clientes;
    no saben qué empleado atendió a quién.
    
    Nuestro producto viene a solucionar esos problemas.

# OBJETIVOS
    
## Objetivo general:
    El objetivo general de este producto es crear una plataforma moderna para administrar barberias.

## Objetivos especificos:
    Digitalizar la reserva de turnos.
    Reducir errores de agenda.
    Facilitar la administración.
    Mejorar la experiencia del cliente.
    Permitir que el sistema pueda crecer en el futuro.


# PUBLICO OBJETIVO
   Durante la primera etapa, el producto estará orientado a barberías pequeñas y medianas que necesiten digitalizar la gestión de sus turnos sin incorporar sistemas complejos o costosos, a futuro cuando el producto escale este abarcara a publicos como Peluquerias, Centros de estetica, Salones de belleza, spas, etc.


# ALCANCE INICIAL (MVP)
    El alcance inicial como primera version del producto se enfocara en:
### Cliente:

    Ver servicios.
    Elegir barbero.
    Elegir fecha.
    Elegir horario.
    Registrarse.
    Reservar.
    
### Administrador:
    
    Dashboard con información resumida.
    Gestión de servicios.
    Gestión de barberos.
    Gestión de clientes.
    Gestión de turnos.


# VISION A FUTURO
   En YANKA concebimos este producto como una plataforma en constante evolución. Nuestro objetivo no es desarrollar una solución temporal, sino un software escalable que pueda adaptarse a las necesidades futuras del negocio y expandirse hacia nuevos mercados relacionados con la gestión de servicios de estética y cuidado personal. Por eso como vision a futuro buscaremos incorporar:

    PWA.
    Notificaciones.
    Estadísticas.
    Recordatorios automáticos.
    Integración con calendarios.
    Pagos online (opcional).
    Tablero de tareas
    Soporte para distintos tipos de negocios relacionados con la estética.
